## Brand & Style

This design system is engineered as an ultra-premium, deeply personal operating system for high agency, disciplined execution, and cognitive clarity. It discards corporate SaaS clutter, vanity gamification, and disruptive animations in favor of a silent, authoritative "cockpit" aesthetic. Built specifically for demanding daily architecture—spanning medical/clinical practice, academic focus, physical training, and enterprise building—the interface functions as an executive instrument of momentum.

### Visual Philosophy
- **Tactile Dark Minimalism:** A near-black spatial canvas engineered through high-purity chromatic dark tiers (`#090A0F`, `#12141C`, `#181B26`), punctuated by hairline structural micro-borders (`#232738`).
- **Precision Energy:** High-contrast kinetic accents in emerald and mint green denote state transitions, completion, and flow-state velocity without aggressive visual noise.
- **Cognitive Quietude:** Functional areas are segmented using semantic chromatic coding, allowing instant situational awareness at peripheral glance while keeping data presentation surgical, calm, and monolithic.

## Colors

The system relies on an intentional dark architecture calibrated to reduce optical fatigue during late-night clinical reviews or dawn training regimes. Surface levels must never use pure `#000000`; instead, they employ deeply saturated midnight obsidian tones with micro-tonal shifts to preserve depth.

### Structural Canvas Tiers
- **Canvas Base (Deep Obsidian):** `#090A0F` — The root viewport background.
- **Surface Level 1 (Container Surface):** `#12141C` — Structural cards, navigation rails, and persistent widgets.
- **Surface Level 2 (Elevated Active Surface):** `#181B26` — Hover states, modal sheets, and prioritized metric nodes.
- **Surface Level 3 (Interactive Inset):** `#1F2332` — Input backgrounds, progress tracks, and recessed toggles.
- **Subtle Boundaries (Hairline Stroke):** `#232738` — 1px structural partitions with exact geometry.

### Accent & Feedback
- **Primary Momentum (Emerald):** `#10B981` — Core confirmation actions, active streak counts, and prime CTAs.
- **Secondary Kinetic (Mint Luminescence):** `#34D399` — High-efficiency highlights, glow reflections, and positive delta values.
- **Data Indicator (Cyan Electric):** `#06B6D4` — Secondary analytical streams, time trackers, and focus clocks.

### Semantic Category Palette
Functional domains possess dedicated non-competing semantic tokens to categorize tasks, schedules, and analytics effortlessly:
- **Clínica:** `#06B6D4` (Cyan Precision)
- **Universidad:** `#8B5CF6` (Deep Violet)
- **Gimnasio:** `#F97316` (Kinetic Amber/Orange)
- **Trabajo Remoto:** `#3B82F6` (Operational Blue)
- **Negocio:** `#EAB308` (Sovereign Gold)
- **Pareja / Personal:** `#EC4899` (Vibrant Rose)
- **Descanso / Recovery:** `#A78BFA` (Soft Lavender)
- **Traslado / Transit:** `#64748B` (Muted Slate)

Typography text tones strictly enforce readability: Primary Text at `#F8FAFC`, Secondary Text at `#94A3B8`, and Disabled/Tertiary Text at `#475569`.

## Typography

The type scale combines **Plus Jakarta Sans** for headers, bold metric values, and primary counters with **Geist** for crisp, monospaced-adjacent tabular data, body text, and tactical checklists.

### Numerical Data & Metric Displays
All numeric indicators (completion percentages, daily calorie burn, study hours, revenue targets, clinical patient counts) must activate tabular numbers via font feature settings (`font-feature-settings: "tnum" on, "cv02", "cv03", "cv04"`). This prevents jitter when numbers update live during active timers or routine completions.

### Tracking and Line Spacing Rules
- Large headlines use compact, negative letter-spacing (`-0.02em` to `-0.03em`) to project architectural density and confidence.
- Micro-labels and tag badges apply tracked uppercase styling (`letter-spacing: 0.04em`) to maintain legibility when rendered against low-contrast dark container backgrounds.

## Layout & Spacing

The layout model is anchored on an 8pt base grid system designed for effortless thumb accessibility on mobile devices while providing a 3-column tactical workstation on widescreen desktop displays.

### Form Factor Behavior
- **Mobile (Viewport < 768px):** Single-column stacked stream. Fluid cards with `margin: 1rem` screen offsets. Daily routine timeline lives in the immediate thumb arc. Bottom-docked floating control capsule provides instant creation triggers (+ Tarea, + Registro Clínico, + Hábito).
- **Tablet (Viewport 768px - 1199px):** Adaptive 2-column layout. Left column hosts the daily timeline, schedule, and priority matrix. Right column isolates metrics, weekly progress graphs, and semantic focus categories.
- **Desktop (Viewport ≥ 1200px):** Ultra-wide, 3-column control cockpit:
  1. *Left Navigation Hub (260px fixed width):* Fluid sidebar containing identity status, calendar navigation, semantic tags, and quick-filter switches.
  2. *Center Primary Stream (Fluid max-width 780px):* Daily agenda, priority focus block, time-blocked execution chunks, and active checklists.
  3. *Right Tactical Panel (360px fixed width):* Health, training volume, active timer/deep-work tracker, streak momentum indicators, and real-time metric analytics.

## Elevation & Depth

This design system rejects deep, muddy drop shadows in favor of a crisp architectural surface stacking model:

### Surface Hierarchy
- **Level 0 (App Shell):** Solid `#090A0F`.
- **Level 1 (Structural Card):** Solid `#12141C` paired with a precise 1px stroke (`border: 1px solid #232738`).
- **Level 2 (Hover / Active Focus / Modal):** Solid `#181B26` with a refined directional top highlight (`border-top: 1px solid rgba(255, 255, 255, 0.08)`, sides and bottom `#232738`).

### Kinetic Glow Radiance
For elements reaching 100% completion, active timers, or primary focus cards:
- **Emerald Pulse Glow:** `box-shadow: 0 0 24px -6px rgba(16, 185, 129, 0.18)`.
- **Category Halo:** Semantic task cards apply a concentrated left boundary border (3px solid `var(--category-color)`) alongside an extremely faint tinted backdrop blur (`rgba(color, 0.04)`).
- **Ghost Overlays:** Sheets and drawer modals use `backdrop-filter: blur(12px)` over a 60% opacity `#090A0F` scrim.

## Shapes

The geometry strikes a calculated balance between industrial precision and tactile warmth. The roundedness value is calibrated to `2`, giving modular containers generous organic corners while buttons and input elements maintain tight, responsive edges.

### Corner Radii Guidelines
- **Structural Cards & Master Containers:** `16px` (`rounded-lg`) up to `20px` (`rounded-xl` on desktop views) to create polished, tactile framing.
- **Buttons, Text Inputs, and Habit Checkbox Squares:** `10px` to `12px` for responsive clickability.
- **Tags, Category Badges, and Numeric Pills:** Fully rounded (`9999px` / capsule shape) to clearly distinguish metadata from executable UI cards.
- **Progress Track Bars:** Pill-shaped capsules with clean overflow clipping for liquid completion fill animations.

## Components

### Buttons & Action Triggers
- **Primary CTA:** Solid emerald fill (`#10B981`) with dark midnight text (`#090A0F`), font weight `600`. On hover, transitions to mint (`#34D399`) with an elevated ambient emerald glow.
- **Secondary Ghost:** Inset surface (`#181B26`), bordered by `#232738`, text color `#F8FAFC`. On hover, border shifts to `#34D399` at 40% opacity.
- **Destructive/Critical:** Surface `#181B26` with border `rgba(239, 68, 68, 0.3)` and text `#EF4444`.

### Daily Habit Checkboxes & Status Triggers
- Custom square triggers (24px x 24px) with an 8px radius.
- **Unchecked:** Background `#12141C`, border 1.5px `#232738`.
- **Completed:** Instantly animates to `#10B981` with an interior checkmark icon in `#090A0F`, accompanied by a subtle tactile micro-bounce (`scale(1.08)` to `scale(1)` over 150ms).

### Category Badges & Metadata Chips
- Height 24px, padding 0 10px, radius 9999px.
- Background: Dynamic semantic color at 12% opacity (e.g., `rgba(6, 182, 212, 0.12)` for Clínica).
- Text: Crisp 11px uppercase label using the exact solid semantic token (`#06B6D4`), paired with a 4px circular glowing status pip.

### Tactical Cards (Habits, Schedule, Tasks)
- Base background `#12141C`, 1px hairline border `#232738`, padding 16px to 20px, radius 18px.
- Category distinction: A 3px left border stripe or semantic badge anchor.
- Hover interaction: Elevates background to `#181B26`, border tone brightens to `#32384E`.

### Form Fields & Inset Inputs
- Height 44px (mobile friendly), background `#181B26`, border 1px solid `#232738`, radius 10px, text `#F8FAFC`.
- Focus state: Border transitions to `#10B981`, with an immediate zero-offset ring `box-shadow: 0 0 0 1px #10B981`.

### Numeric Metric Counter Panels
- Dedicated high-impact widget displaying current streak, target volume, and percentage completion.
- Layout: Large tabular numeric header (`metric-display`) sitting atop an 8px tall rounded progress bar. Fill gradient flows from `#10B981` to `#34D399`. Secondary delta text indicates weekly progress comparison in clean muted slate (`#94A3B8`).
