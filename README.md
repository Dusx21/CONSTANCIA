# CONSTANCIA

SPA personal de productividad, construida con React + Vite + Tailwind CSS.

## Ejecutar

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

La app usa `localStorage` mediante `src/services/storageService.js`, está preparada para PWA mediante el manifest y es compatible con despliegue estático en Vercel.
